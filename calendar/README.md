# Content calendar

One page per month, named `YYYY-MM.md`. One row per planned post.

- [October 2026](2026-10.md)
- [November 2026](2026-11.md)

## Rhythm (proposal)

- **Learning Community channels:** two posts a week, Tuesday and Friday. If that is too much, keep Tuesday.
- **CES:** at least one volunteer post a month, with the EU acknowledgement.
- **Enraizar no Interior:** at least one post a month showing the co-financing logos.

A post planned here is considered agreed — it needs no further sync (see [guidelines](../guidelines.md)).

## The columns

| Column | What to write |
|---|---|
| **Date** | Planned publishing day |
| **Channel** | Where it goes — names as in [the channel list](../channels.md) |
| **Pillar** | Life · Learning · People · Community · Opportunities |
| **Purpose** | Connect · Events · Volunteers · Funding · Families |
| **What** | One line: the story |
| **Material from** | Who is closest to the activity and supplies photos and facts |
| **Fund** | `CES`, `ENR` (Enraizar) or `—`. If not `—`, logos and funding sentence are mandatory |
| **Status** | `idea` → `material in` → `ready` → `published` |

## Status meanings

- **idea** — a slot is reserved; nothing exists yet
- **material in** — photos and facts have arrived in Drive
- **ready** — text written, consent and facts checked
- **published** — it is out; paste the link into the *What* cell. If *Fund* is not `—`, also add it to the [evidence log](../funded-projects/evidence-log.md)

How to add or change a row: [add a post to the calendar](../how-to/add-a-post-to-the-calendar.md).
