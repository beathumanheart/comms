# Funded projects — visibility

When a project is funded, saying so publicly is **part of the project**, and we must be able to prove we did it.

| Project | Funder | Page |
|---|---|---|
| CES — European Solidarity Corps volunteers | European Union | [CES page](ces.md) |
| Enraizar no Interior | European Union through Alentejo 2030 (ESF+) | [Enraizar no Interior page](enraizar-no-interior.md) |

Proof of everything published: [the evidence log](evidence-log.md).

## The routine

**Verify → Prepare → Publish → Prove → Report**

1. **Verify** — read what the actual agreement requires. This page summarises; the agreement decides.
2. **Prepare** — the exact funding sentence and the right logo files, ready to copy.
3. **Publish** — on the agreed channels, with sentence and logo.
4. **Prove** — the same day: link + screenshot, one line in the evidence log.
5. **Report** — at the deadline the log *is* the evidence.

Handoff: volunteers and teams supply stories and facts → comms publishes → Descalças checks the evidence.

## The rule

Confirm every visibility obligation against the actual project agreement. If this page and the agreement disagree, the agreement wins — then fix this page.
