# Log evidence for a funded project

Do this the same day you publish anything that mentions **CES** or **Enraizar no Interior**. It takes two minutes.

1. **Screenshot** the published post or page so that the **logo and the funding sentence are visible**, together with the date and the name of the channel.
2. **Name** the file `YYYY-MM-DD_project_channel.png` — for example `2026-10-09_CES_facebook.png`.
3. **Upload** it to the evidence folder in the shared Drive. Copy its link.
4. Open the [evidence log](../funded-projects/evidence-log.md), click **Edit this page**, add a line:

```
| 2026-10-09 | CES | Meet the volunteers | Facebook | https://link-to-post | https://link-to-screenshot | yes | your name |
```

5. Commit changes.

For printed things (posters, flyers, banners at events): take a **photo in place**, and log it the same way with channel `On site` or `Print`.

If the logo or sentence is missing from what was published: fix the post first, then screenshot.
