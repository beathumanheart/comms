# Start a new season

Once a year, or whenever the team rotates.

1. Copy the folder `seasons/2026-27/` and name the copy after the new season, for example `seasons/2027-28/`.
2. In the new folder:
    - `owners.md` — replace the names.
    - `next-steps.md` — keep what is still open, delete what is done.
    - `announcement.md` — update and send.
3. Open `site/config.json` and change `"season": "2026-27"` to the new folder name. The menu and the home page now point to the new season.
4. Search the pages for the old season name and update the few links that mention it.
5. [The channel list](../channels.md) — check every link still works and who holds each login. **Change the passwords** of shared accounts when someone leaves.
6. Access: remove people who left, invite the new ones.
7. [Funded projects](../funded-projects/) — which projects are still running? Add new ones, each with its own page.

Leave the old season folder in place. It is the record of who decided what.

The model (how it fits together) and the rules do not change with the season. Change them only when the team agrees to.
