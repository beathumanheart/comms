# Edit a page

You need a free GitHub account that has been invited to this space. No software.

1. On the website, open the page you want to change and click **Edit this page** (under the title).
2. GitHub opens with the text of that page. Change the text. Click **Preview** to see how it will look.
3. Click **Commit changes…**, write in a few words what you changed ("October: added market post"), click **Commit changes**.

About a minute later the website shows the new version, with today's date and **your name** under the title.

## The few signs you need

| You type | You get |
|---|---|
| `# Title` / `## Section` | Headings |
| `**bold**` | **bold** |
| `- item` | A bullet |
| `- [ ] task` | A checkbox |
| `[text](https://…)` | A link |
| `\| a \| b \|` | A table row |

## Tables

A table row is cells separated by `|`. To add a row, copy an existing line, paste it below, change the words. Keep the same number of `|`.

## Your name on the page

The website shows the name of your GitHub profile. To change it: on GitHub, click your picture → **Settings** → **Name**. If you would rather not use your real name there, tell whoever set up the space; they can set the name the website shows for you.

## If something goes wrong

Click **See all changes** next to the date under the title: every earlier version of the page is kept, with who changed what. Nothing is ever lost, and you cannot break anything permanently.
