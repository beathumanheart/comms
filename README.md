# Learning Community — external communications

The handbook of the external comms team for the **Learning Community** (Comunidade de Aprendizagem: Bosque Escola Avelãs + Planeta Alecrim) and its links to **Descalças**.

**Read it as a website:** the address is shown in this repository under *Settings → Pages* once the site is published.

> Status: **draft for team review**, October 2026.

## What is where

```
guidelines.md        the rules, one page
channels.md          list of media: what each channel is for
architecture/        the agreed model — no names, reusable every year
seasons/2026-27/     names, decisions and next steps for this season
calendar/            one page per month of planned posts
funded-projects/     CES and Enraizar: what we must show, and the proof
how-to/              short step-by-step instructions
site/                the website machinery — not needed for editing pages
```

Two principles:

1. **No names in the model.** The architecture, the rules and the channel list talk about *roles*. Names live only in `seasons/`. When the team rotates, copy the season folder and change the names.
2. **Text here, media in Drive.** Photos, videos, logos and screenshots stay in the shared Google Drive; we only link to them.

## Editing

On the website, every page has an **Edit this page** button. Change the text, click **Commit changes**; a minute later the website is updated and shows the date and your name under the title. See [how-to/edit-a-page.md](how-to/edit-a-page.md).

First-time setup: [how-to/set-up-this-space.md](how-to/set-up-this-space.md).

This repository and its website are public. Never put here: passwords, children's names or photos, private contact details.
